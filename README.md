# Divine Favour International School website

The website for Divine Favour International School, Low-Cost, Jasikan, Oti Region, Ghana.
Live at **https://www.divinefavourschool.com**.

It is a plain HTML and CSS site with no build step, hosted free on GitHub Pages from the `main` branch.

## Pages

| File | Page |
|---|---|
| `index.html` | Home |
| `about.html` | About us: story, mission and vision, core values, founders |
| `admissions.html` | Why choose us, classes, a day at school, Now enrolling and the Apply now form |
| `gallery.html` | Photos |
| `fees.html` | Pay school fees (Mobile Money) and Sponsorships |
| `contact.html` | Contact details |
| `404.html` | Shown when a page is not found |

The header, footer and Get in touch box are repeated in each page, so change them in every file.

## Common edits

- **Class ages:** the orange labels in the "Our classes" section of `admissions.html` (currently placeholders).
- **Photos:** `assets/img/`. Blurred page backgrounds are in `assets/img/bg/`.
- **Admission form:** replace `assets/docs/divine-favour-admission-form.pdf`, keeping the same file name.
- **Colours and fonts:** the variables at the top of `styles.css`.

## Domain

`CNAME` tells GitHub Pages to serve the site at www.divinefavourschool.com. Don't delete it.
